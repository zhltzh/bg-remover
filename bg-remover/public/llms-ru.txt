# AI BG Remover - Обзор сайта
> Бесплатный онлайн-инструмент для удаления фона с помощью ИИ. Вся обработка выполняется локально в вашем браузере.

## Brand
- Название: AI BG Remover
- Описание: Бесплатный онлайн-инструмент на основе ИИ для удаления фона изображений с пакетной обработкой и скачиванием качественных PNG с прозрачным фоном. Всё работает локально в браузере — изображения никогда не загружаются на сервер.
- Язык: Русский (ru-RU)

## Core Capabilities
- Автоматическое удаление фона изображений
- Пакетная обработка нескольких изображений
- Поддержка JPG/PNG/WEBP/AVIF/GIF/SVG
- Несколько доступных ИИ-моделей (BRIA RMBG/MODNet/U²-Net)
- Работает локально в браузере, загрузка не требуется

## Tech Stack
- ИИ-движок: ONNX Runtime Web
- Ускорение: WebGPU, WebAssembly SIMD
- Модели: BRIA RMBG v1.4, MODNet, U²-Net
- Фронтенд: Vue 3, Nuxt 3, Tailwind CSS

## Key Facts
- Вся обработка выполняется полностью в браузере; изображения никогда не покидают ваше устройство
- Пакетная обработка поддерживается без ограничений по количеству и размеру
- 100% бесплатно, регистрация и вход не требуются
- При первом использовании загружается ИИ-модель (~42 МБ); при последующих использованиях всё мгновенно благодаря кэшированию IndexedDB
