# AI BG Remover - 사이트 개요
> 무료 온라인 AI 배경 제거 도구. 모든 처리는 브라우저 내에서 완료됩니다.

## Brand
- 이름: AI BG Remover
- 설명: 이미지 배경을 무료로 자동 제거하는 온라인 AI 도구. 여러 이미지를 일괄 처리하고 고품질 투명 PNG를 다운로드할 수 있습니다. 모든 처리는 브라우저에서 완료되며 이미지가 서버에 업로드되지 않습니다.
- 언어: 한국어 (ko-KR)

## Core Capabilities
- 이미지 배경 자동 제거
- 여러 이미지 일괄 처리
- JPG/PNG/WEBP/AVIF/GIF/SVG 지원
- 여러 AI 모델 사용 가능 (BRIA RMBG/MODNet/U²-Net)
- 브라우저에서 실행, 업로드 불필요

## Tech Stack
- AI 엔진: ONNX Runtime Web
- 가속화: WebGPU, WebAssembly SIMD
- 모델: BRIA RMBG v1.4, MODNet, U²-Net
- 프론트엔드: Vue 3, Nuxt 3, Tailwind CSS

## Key Facts
- 모든 처리는 브라우저에서 완료되며 이미지가 기기 밖으로 전송되지 않습니다
- 일괄 처리를 지원하며 개수·크기 제한이 없습니다
- 100% 무료, 회원가입·로그인 불필요
- 첫 사용 시 AI 모델(약 42MB)을 다운로드. 이후에는 IndexedDB 캐시로 즉시 사용 가능
