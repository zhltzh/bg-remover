# AI BG Remover - Site Overview
> Free online AI background remover. All processing runs locally in your browser.

## Brand
- Name: AI BG Remover
- Description: Free online AI background remover for batch image processing with high-quality transparent PNG download. Everything runs locally in the browser - images are never uploaded to a server.
- Language: English (en-US)

## Core Capabilities
- Automatic image background removal
- Batch processing of multiple images
- Supports JPG/PNG/WEBP/AVIF/GIF/SVG
- Multiple AI models available (BRIA RMBG/MODNet/U²-Net)
- Runs locally in the browser, no uploads required

## Tech Stack
- AI Engine: ONNX Runtime Web
- Acceleration: WebGPU, WebAssembly SIMD
- Models: BRIA RMBG v1.4, MODNet, U²-Net
- Frontend: Vue 3, Nuxt 3, Tailwind CSS

## Key Facts
- All processing runs entirely in the browser; images never leave your device
- Batch processing supported with no limits on count or size
- 100% free, no registration or login required
- First use downloads the AI model (~42MB); subsequent uses are instant thanks to IndexedDB caching
