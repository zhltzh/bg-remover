# AI BG Remover - Présentation du site
> Suppression de fond d'image gratuite par IA en ligne. Tout le traitement s'exécute localement dans votre navigateur.

## Brand
- Nom : AI BG Remover
- Description : Outil en ligne gratuit pour supprimer le fond d'image par IA, avec traitement par lots et téléchargement de PNG transparent haute qualité. Tout s'exécute localement dans le navigateur - vos images ne sont jamais envoyées sur un serveur.
- Langue : Français (fr-FR)

## Core Capabilities
- Suppression automatique du fond des images
- Traitement par lots de plusieurs images
- Prise en charge de JPG/PNG/WEBP/AVIF/GIF/SVG
- Plusieurs modèles IA disponibles (BRIA RMBG/MODNet/U²-Net)
- S'exécute localement dans le navigateur, aucun téléversement requis

## Tech Stack
- Moteur IA : ONNX Runtime Web
- Accélération : WebGPU, WebAssembly SIMD
- Modèles : BRIA RMBG v1.4, MODNet, U²-Net
- Frontend : Vue 3, Nuxt 3, Tailwind CSS

## Key Facts
- Tout le traitement s'exécute entièrement dans le navigateur ; les images ne quittent jamais votre appareil
- Traitement par lots pris en charge sans limite de nombre ni de taille
- 100 % gratuit, aucune inscription ni connexion requise
- La première utilisation télécharge le modèle IA (~42 Mo) ; les utilisations suivantes sont instantanées grâce au cache IndexedDB
